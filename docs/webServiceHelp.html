--- Basic html index request ---

Endpoint

GET /

Retrieves a basic html page giving functional examples of calls to the API

Path Parameters

Parameter Type Description
- - -

Example Request

http
GET / HTTP/1.1
Host: localhost:8080

Response

Success (200 OK)

The response will return the user's details in JSON format.

Response Body
html
{
  <PAGE HTML>
}

Error Codes

Code Description Solution
500 Internal Server Error Contact the PolyGlot support

--- Get File Metadata ---

Endpoint

GET /metadata

Retrieves the details of a specific user by their user ID.

Path Parameters

Parameter Type Description
file string name of language file to retrieve metadata for (all available files queryable)

Example Request

http
GET / HTTP/1.1
Host: localhost:8080

Response

Success (200 OK)

The response will return a page with all served PolyGlot files and some examples of how to request elements of them (or the whole file)

Response Body
json
{
  "id": 12345,
  "username": "johndoe",
  "email": "john.doe@example.com",
  "first_name": "John",
  "last_name": "Doe",
  "created_at": "2023-01-01T12:00:00Z",
  "updated_at": "2023-01-10T12:00:00Z"
}

Error (404 Not Found)

The response will return an error message in JSON format if the user is not found.

Response Body
json
{
  "error": {
    "code": 404,
    "message": "User not found"
  }
}

Error Codes

Code Description Solution
401 Unauthorized Check your access token and ensure it's valid
404 User not found Verify the user ID and ensure it's the correct user ID
500 Internal Server Error Contact the API support team if the issue persists
